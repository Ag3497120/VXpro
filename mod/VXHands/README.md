# VX Hands 0.2.0

Experimental cross-platform script mod for Cyberpunk 2077. The host turns hand gestures into ordinary inputs; the script displays a reload message when the game delivers the Reload action. It does not read or modify game memory.

`r6/scripts/vxhands.script` uses the official wrapper call and CName forms seen in the installed cross-platform mod. This revision has not been cooked by the official mod.io compiler or verified in game. The host handles magazine stages externally; the script does not yet implement staged gameplay. No compiled patch is included. `info.json` is the author metadata; the installed example has a mod.io-generated `about.json` with its assigned ModID, which is not invented here.
