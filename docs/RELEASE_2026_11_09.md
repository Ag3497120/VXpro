# Accepted hand-tracking checkpoint — 2026-11-09

This source checkpoint follows the user's report that vehicle behavior improved,
and their request to publish the installed state to `hand-tracking`. `main` is
kept separate. It retains the previous hand/weapon, graphics and head-stability
checkpoint; no new FPS result is claimed.

## Changes since the November 8 publication

- A world-camera sample must carry a valid perspective projection of its own.
  Orthographic, invalid and zero-lens foreground candidates cannot replace the
  camera for a world image. The owning command buffer still keeps view and lens
  together. This addresses the reproduced VR-only blackout path.
- Vehicles request the same existing peripheral extension as ordinary walking.
  Left-stick steering is classified as a controller turn only while mounted;
  ordinary walking/strafe does not move the physical head reference.
- VR vehicle vertical look now comes from the head, as requested by the user.
  The right stick's vertical camera input is suppressed in VR; left-stick motion,
  steering, triggers and right-stick horizontal look remain on their existing
  paths. Flat mode and explicit `VXMAC_STICK_PITCH=1` retain vertical stick look.
- Opt-in direct CDPR account/cross-progression compatibility: HTTPS transport,
  certificate-format compatibility, restricted browser handoff, read-only standard
  CA-path mapping and startup restoration through the owned SDK's genuine API.
  The player signed in, saw a cloud save and loaded it. Native startup restoration
  has also been observed. This does not establish upload roundtrip, every save's
  compatibility or indefinite account persistence. See [DIRECT_CLOUD.md](../DIRECT_CLOUD.md).

alone did not undo that setting. Keep graphics settings separate from source changes.

[The tested startup flags](configs/hand-tracking-2026-11-09.args.txt) are an explicit
experimental preset. Networking remains opt-in: it also needs the private standard

Rectangular borders may still occur in story/constrained camera views; all
vehicles, perspectives and transitions are not verified. Same-frame peripheral
extension cannot draw unseen world geometry. Weapon-specific contact, sight and
reload/slide issues retain their previous limits. The immediate standard-controller /
tracked-hand mode switch remains future work. No NPU gain or physical display FPS
is assigned to this checkpoint.
