# Apple Vision Pro 単体で Cyberpunk 2077：Mac App Store 版ルート（Preview 0.1）

[English](VISION_PRO_CYBERPUNK_MAC.md)

**VXpro**（[VeRantyx](https://github.com/Ag3497120/VeRantyx) の VX Mac ルート）は、**Mac App Store 版 Cyberpunk 2077** を **Vision Pro 本体だけで** 動かします。起動後は PC も
Mac も不要で、ストリーミングもしません。Mac 版のゲームは visionOS と同じ arm64 の Metal コードなので、VX Mac はその
コードをそのままネイティブに実行します（エミュレーションも変換もありません）。ゲームはイマーシブ空間に VR で表示され、
頭の向きでゲームのカメラが回り、メニューは部屋に固定されたパネルに出ます。

これは Xcode とコマンドラインに慣れた人向けの **実験的プレビュー** です。**自分で購入した** ゲームを、**自分の**
ヘッドセットで、**自分の** Apple 開発者チームの署名で動かすための手順書です。VXpro はゲームのファイルを一切配布
しません。技術的な背景と経緯：[`DESIGN.md`](DESIGN.md)（英語）。もう一つのルート（Windows / Steam 版を
VXRuntime で動かす）は [VeRantyx](https://github.com/Ag3497120/VeRantyx) にあります。

> **VX Mac Host をヘッドセットから削除しないでください**（`--remove-existing-content` 付きのインストールも不可）。
> アプリを削除するとコンテナごと消え、約 158 GB のゲームデータの複製と **セーブデータ** も失われます。
> `tools/vxmac_cyberpunk.py install` での再インストールなら残ります。

> **こまめにセーブしてください。** このアプリは visionOS が 1 アプリに許すメモリの上限近くで動いています（「制限」
> 参照）。visionOS がアプリを終了させると、最後のセーブ以降の進行は失われます。長く遊ぶ前にはゲームの手動セーブを
> 使い、携帯機で遊ぶとき以上の頻度でセーブしてください。

## 現在できること

| | |
|---|---|
| メインメニュー、キャラクター作成 | 可 |
| ゲーム本編 | 可（確認済み：冒頭の屋内。その先のエリアは未確認） |
| 表示 | VR：頭のヨー／ピッチでゲームのカメラが回り、各目の映像はコンポジタの 90 Hz で再投影 |
| ゲームのフレームレート | 約 20〜30 fps（ゲーム自体の速度。90 Hz の再投影で頭の動きは滑らかに保たれる） |
| メニュー、ムービー、ロード画面 | 目の前の空間に固定されたパネルに表示、周囲は暗転（振り返ると置き直される） |
| 切り替え | 自動：ゲームのカメラがマウスルックに従う間は VR、それ以外はパネル（短いフェード付き） |
| 入力 | ゲームコントローラ（Joy-Con で確認）、パネル上のハンドポインタ、Bluetooth キーボード／マウス |
| メモリ | ゲーム中で約 6.4〜6.6 GB（アプリが使える上限は約 8.2 GB） |

> 確認環境：Vision Pro（M2）・visionOS 26。上のフレームレートは 1280x720（`p720fixed`）のもの。音も出ます。Phantom Liberty の序盤（ドッグタウン、ソングバード）まで遊べており、ヘッドセットのホームビューからの起動も Mac からの `launch` と同じに動きます。

## 必要なもの

> **ゲームの版について：** 現在対応しているのは Cyberpunk 2077 **2.3.2**（2025 年の Mac App Store 版）だけです。最新の Mac App Store の更新（App Store の版 1.0.4、2026 年 10 月 22 日公開）には **まだ対応していません。近日中に対応予定です。** すでに更新されている場合、ツールは `doctor` / `prepare` の段階で何も変更せずに止まります。

- **Apple Vision Pro**：**デベロッパモード** をオン（設定 > プライバシーとセキュリティ > デベロッパモード）にし、
  Xcode（Window > Devices and Simulators）で Mac とペアリング済みであること。アプリの対象は visionOS 26.0 以降。
  M2 の Vision Pro で確認しています。
- **ヘッドセットの空き容量 約 160 GB**：ゲームデータが 158.5 GB（10 進。Phantom Liberty と全言語の音声を含む）と
  アプリ本体。空き容量は 設定 > 一般 > ストレージ で確認してください（Mac からは読めません）。Windows ルートも
  入れている場合、そちらは別に約 67 GB を使います。
- **Apple シリコンの Mac**：**Xcode 26** 以降（visionOS SDK 込み）、`xcodegen`（`brew install xcodegen`）、
  Python 3、作業コピーとビルド用に **約 5 GB の空き**。リポジトリは **スペースを含まないパス** に clone してください。
- **有料の Apple Developer Program メンバーシップ**：アプリには *Increased Memory Limit* と *Extended Virtual
  Addressing* の 2 つのエンタイトルメントが必要で、無料の個人チームでは App ID に追加できません。アプリは **自分の**
  チームと **自分の** バンドル ID で署名されます。
- **自分で購入した Mac App Store 版 Cyberpunk 2077 バージョン 2.3.2** が Mac にインストールされていること（外付け
  ドライブなど、Mac から読める場所ならどこでも可）。実行ファイル `Contents/MacOS/Cyberpunk2077` がこのビルドと
  完全に一致する必要があります：`sha256 3907f316f6adf9dd8188be82aeea9ae161445b2e1f6d25cf08c87b8a3ae6b421`。
  `doctor` が確認します。他のバージョン（他のパッチ、Steam / GOG / Epic の Mac 版）は拒否されます。
- **時間**：ビルドは数分。158 GB をネットワーク越しにヘッドセットへ複製するほうが長くかかります（Windows ルートでは
  devicectl が毎秒 30〜40 MB 程度：1〜2 時間以上を見込んでください。その間ヘッドセットをスリープさせず、同じ
  ネットワークに置いてください）。

> このルートでの複製時間はまだ測っていません。1〜2 時間以上を見込んでください。

## ツール

すべて 1 つの案内付きツールで行います。リポジトリのルートで実行してください：

```sh
tools/vxmac_cyberpunk.py doctor  --game "/Applications/Cyberpunk2077.app"
tools/vxmac_cyberpunk.py prepare --game "/Applications/Cyberpunk2077.app" --team <TEAMID> [--bundle-id <id>] [--device <id>]
tools/vxmac_cyberpunk.py build
tools/vxmac_cyberpunk.py install
tools/vxmac_cyberpunk.py copy                  # 再開可能。最後に全ファイルのサイズを照合
tools/vxmac_cyberpunk.py launch
tools/vxmac_cyberpunk.py fov --max 110         # 任意：「推奨設定」参照
tools/vxmac_cyberpunk.py settings --profile p720fixed --set FieldOfView=110
tools/vxmac_cyberpunk.py pull --tag t1         # ログを Mac に回収
```

`install`、`copy`、`settings`、`launch`、`pull` は `--dry-run` を受け付けます（`devicectl` のコマンドを表示するだけで、
デバイス上では何も実行しません）。ツールが作るものはすべて `build/cyberpunk/`（git の管理外）に入ります。

> 注：案内付きツールはこのプレビューで新しく作ったもので、まだ他の人が最初から最後まで通して実行していません。途中で失敗したら、その出力を添えて Issue を立ててください（個人情報は消してから）。

### 各ステップの内容

1. **元のゲームは一切変更しません。** `prepare` は App Store のバンドルを読むだけで、ゲームの 4 つのコードイメージ
   （`Cyberpunk2077`、`libGameServicesAppStore`、`libBink2MacArm64`、`libREDGalaxy64`）の **作業コピー** を
   `build/cyberpunk/prepared/` に書き出します。コピーで変わるのはロードコマンドだけです：プラットフォーム
   （macOS → visionOS）、ライブラリのパス（macOS 専用ライブラリ → VX Mac のシム）、コード署名（削除。ビルド時に
   自分の署名を付けます）、そして実行ファイルをホストアプリが読み込める動的ライブラリにする変更です。実行ファイルの
   コピーでは、エンジンのメモリプールの大きさを決める 15 個の命令を変更します（Windows ルートと同じ変更：64→16 GB、
   32→8、16→8、4 GB のプールはそれぞれ 1 GB）。visionOS のアプリは Mac よりアドレス空間がずっと小さいためです。
   これは実行ファイルの SHA-256 に結び付いており、それ以外のファイルには適用を拒否します。DRM、ストア、オンライン、
   セーブに関わるコードは何も変えません。続いてシムをビルドし、コピーが読み込むすべてのシンボルが visionOS 上で
   見つかることを確認します。
2. **build**：VX Mac Host を `xcodegen` と `xcodebuild` でビルドします。自分のチームとバンドル ID（既定は
   `com.<team>.VXMacHost`）を使い、作業コピーを組み込んで自分の署名を付け、組み込まれたことと 2 つのエンタイトル
   メントが付与されたことを確認します。ビルドしたアプリにはゲームのコードが入っているので **共有しないでください**。
3. **install**：`xcrun devicectl device install app` だけを行います。更新ではアプリのコンテナ（データ、セーブ）は
   残ります。
4. **copy**：ゲームの `Contents/Data` をアプリのコンテナの `Documents/Cyberpunk2077.app/Contents/Data` に複製します。
   `engine` と `r6` を先に、続いてアーカイブを 1 つずつ、1 項目につき `devicectl device copy to` を 1 回、最大 8 回
   試行します。完了した項目は記録されるので、`copy` をもう一度実行すれば続きから再開します。ヘッドセット上では
   `archive/Mac` を `archive/mac` にします（ゲームは小文字で探し、visionOS のファイルシステムは大文字小文字を区別
   します）。最後にヘッドセット上の全ファイルのサイズを手元のインストールと照合します。複製するのはデータフォルダ
   だけで、セーブ、設定、アカウント情報は複製しません。複製中に `install` しないでください（複製の接続が切れます）。
5. **launch**：自分のバンドル ID を `devicectl device process launch` で起動します。ヘッドセットを装着してロックを
   解除しておいてください。ホストがデータを見つけ、専用のスレッドでゲームを開始し、イマーシブ空間を開きます。
   `--restart` は動作中のものを先に終了させます（**セーブしていない進行は失われます**）。
6. **settings**（任意）：ゲームは初回起動時に `UserSettings.json` を書きます。`settings` はそれをヘッドセットから
   取り出し、元のファイルを `build/cyberpunk/settings/` に残し、GPU 負荷のプロファイル（`p900`、`p720`、
   `p720fixed`：出力解像度と動的解像度。アンビエントオクルージョン、ローカル／コンタクトシャドウ、モーションブラーは
   オフ）を適用して戻します。ゲームは終了時に自分の設定を保存するので、ゲームが動いていないときだけ使えます。
7. **pull**：`vxmac_host.jsonl`（ホストのイベント、2 秒ごとのメモリ）と `vxmac_program.log`（ゲームの出力）を
   `build/cyberpunk/logs/<tag>` に回収します。ファイルパスやデバイスの情報を含むので、投稿する前に中身を確認して
   ください。

## 推奨設定

| 設定 | 値 | 理由 |
|---|---|---|
| アスペクト比 | 16:9 | 表示側の投影はゲームの 16:9 のフレームを前提にしています |
| 解像度 | **1280x720、MetalFX パフォーマンス**、動的解像度オフ | ヘッドセットが 90 Hz を保てる。1600x900 は M2 で約 40 Hz |
| 視野角（FOV） | **110** | 目の視野をより広く覆う。ゲームのスライダーはそこまで届かないので、先に範囲を広げる |

```sh
tools/vxmac_cyberpunk.py fov --max 110                                  # patch_fov.py 110：スライダーの範囲（ヘッドセット上の作業コピーだけ）
tools/vxmac_cyberpunk.py settings --profile p720fixed --set FieldOfView=110
```

どちらもゲームが動いていないときだけ使えます。`fov` はヘッドセット上の作業コピーの
`r6/config/settings/platform/mac/options.json` で FieldOfView スライダーの最大値を変えます（App Store のバンドルは
変えません）。変更前のファイルは `build/cyberpunk/settings/` に残り、`tools/patch_fov.py restore <file>` で戻せます。

`settings` のプロファイル（`tools/cp_settings.py`。どれもアンビエントオクルージョン、ローカル／コンタクトシャドウ、
モーションブラー、顔のタンジェント更新をオフにします）：

| プロファイル | 出力 | アップスケーリング |
|---|---|---|
| `p720fixed`（推奨） | 1280x720 | MetalFX パフォーマンス、固定 |
| `p720` | 1280x720 | 動的解像度 50〜65 % |
| `p720b`、`p720q` | 1280x720 | MetalFX バランス／クオリティ（重い） |
| `p900`、`p900perf` | 1600x900 | 動的解像度／MetalFX パフォーマンス（M2 で約 40 Hz） |
| `tall1040*` | 1040x1004 | 正方形に近いフレームの実験（非推奨） |

`--set NAME=VALUE` で他の設定も名前で変えられます。例：`HudSafezoneHor=0.5`（HUD を内側に）、`HudScaling=110`。

## 操作

- **頭**：3D のゲームプレイ中は、頭のヨーとピッチでゲームのカメラが回ります（マウスの動きとしてゲームに送られます）。
  ゲームのフレームの間は、コンポジタが各目の映像を 90 Hz で再投影します。メニュー、ムービー、ロード画面ではゲームは
  パネルに表示されます。手動で切り替えるには、下の「ヘッドセットでの操作」を参照してください。
- **コントローラ**（visionOS が対応するもの。Joy-Con で確認）：ゲーム自体の Mac 版コントローラ対応で動きます。頭で
  カメラを操作している間、**右スティックは左右の回転（ヨー）だけ** が効きます。上下はピッチを頭に任せるため無視され
  ます。
- **手**：パネル上では、指した位置がポインタになり、ピンチでクリック、ピンチしたまま上下に動かすとスクロールです。
- **キーボード／マウス**：Bluetooth のキーボードとマウスは Mac の入力としてゲームに届きます。

> まだないもの：向きを正面に戻す（リセンター）操作。このプレビューは Joy-Con で遊んでいます。ほかのコントローラーは未確認です。

## ヘッドセットでの操作

VX Mac Host が自分で読み取る手のジェスチャーです。VR（頭で見回すモード）中のピンチは、ゲームには届きません。

| ジェスチャー | 動作 |
| --- | --- |
| **両手で同時にピンチして 1 秒、離す（3 秒より前）** | **VR**（頭で見回す）と **スクリーン**（世界に固定したパネルにゲームを表示し、見回せる）を切り替えます。1 秒間「VR」または「Screen」と表示されます。下の自動切り替えが間違っているときに使ってください。VR に戻ると、頭の上下の角度をあらためてゲームに送ります。手動で VR にした状態は、自動の判定も VR になった時点で自動に戻ります。 |
| **片手でピンチして 1 秒**（VR 中） | warp モード（ゲームのフレームの合間に、頭の動きに映像をどう合わせるか）を順に切り替えます。1 秒間モード名が表示されます。 |
| **両手のピンチを 3 秒続け、もう一度両手でピンチ** | ゲームを安全に終了します。3 秒で「終了しますか？もう一度両手でピンチ」が 6 秒間出ます。そのあいだに両手でピンチすると終了します（VR／スクリーンの切り替えは起きません）。 |

### 安全な終了のしかた

- **ヘッドセット内で**：両手のピンチを 3 秒続け、もう一度両手でピンチします。またはアプリのウインドウの **Quit game**
  をタップします（アプリを開いたとき、没入表示が開く前に出ます）。
- どちらもゲーム自身の終了処理で終わります。Mac の Cmd+Q／終了メニューと同じです（`[NSApp terminate:]` からゲームの
  `applicationShouldTerminate:`）。ゲームの終了処理が走ってからアプリが閉じます。強制終了はしません。
- **アプリをそのまま閉じた場合**（Digital Crown、バックグラウンドへの移行）：ゲームはすぐ一時停止し（GPU の処理なし、
  非アクティブ）、バックグラウンドで 10 秒たつと同じ方法で終了を求めます。10 秒以内に戻れば再開します。
  `VXMAC_BG_QUIT_S=<秒>` で時間を変えられます（0 で無効）。
- 終了する前にゲーム内でセーブしてください。セーブ中にアプリを強制終了しないでください。

warp モード（ピンチで切り替わる順）。表示には番号と名前が出ます（例：「補正 6：回転＋固定の立体」。端末の言語で表示）。

| モード | 名前 | 内容 | ゆがみ | 立体感 | 使う場面 |
| --- | --- | --- | --- | --- | --- |
| **6**（既定） | 回転＋固定の立体 | フレーム全体を頭に合わせて回し、各目のずれをゲームの深度から一定の半 IPD で作る | なし | あり | 普段のプレイ |
| 2 | 回転のみ | フレーム全体を回す。深度は使わない | なし | なし（無限遠の平面） | 立体感より安定を取りたいとき |
| 5 | 補正なし | ゲームが描いたままのフレーム（コントローラーで向きを変えたときと同じ） | なし | なし | 比較用。振り向くと約 0.1 秒遅れる |
| 0 | 深度＋頭の位置 | ゲームの深度で画素ごとに再投影し、頭の移動も反映 | 目立つ（ゴムのよう） | あり | 理論上もっとも正確 |
| 1 | 深度・回転のみ | モード 0 から頭の移動を除いたもの | 少し | あり | |
| 3 | 深度＋頭の位置（3 cm） | モード 0 で頭の移動を 3 cm までに制限 | 少し | あり | |
| 4 | 画像から測るカメラ | カメラの向きを画像の動きから測る | 場合による | あり | 実験的 |

自動で切り替わるもの：

- **HUD**：ゲームの UI（ミニマップ、クエスト、弾数、拾得の通知、チュートリアル）をシーンから取り外し、正面に 1 枚の
  パネル（左右約 ±28°）としてまとめて表示します。画面の端に UI が残ることはありません。字幕は中央の少し下に出します。
- **シーンの上に出るメニューや案内**（ラジオ、スマホ、大きなポップアップ）：フレーム全体（シーンとメニュー）を、暗い背景の
  上に中央のパネル（±30°）で表示します。
- **ムービー**：ゲームが約 9 秒間まったく頭の動きに反応しないと、世界に固定したスクリーンに切り替わります。画像が頭に
  付いてくるようになると VR に戻ります。
- **メニュー、ロード、ロゴ**：スクリーン表示です。

乗り物でのヒント：ゲームの **一人称の運転カメラ** を使ってください。三人称の乗り物カメラは自動で回り込んだり正面に戻ったり
するので、頭の動きに 1 対 1 で付いてきません。

## オプション（環境変数）

起動時に `tools/vxmac_cyberpunk.py launch --env NAME=VALUE`（複数可）で渡すか、アプリのコンテナの
`Documents/vxmac_args.txt` に `-env NAME=VALUE` の行を書きます（ホームビューから開いたときにも使われます）。

| 変数 | 既定 | 内容 |
|---|---|---|
| `VXMAC_FSR=1` | オフ | フレーム中央の超解像を Neural Engine で（モデルが必要：`build` が coremltools で作る） |
| `VXMAC_FSR_CROP`、`VXMAC_FSR_MODEL` | モデルの大きさ、`vxfsr_512x288` | 超解像する領域のフレーム幅に対する割合、モデル名 |
| `VXMAC_FOVEATE=1` | オフ | CompositorServices のフォビエーション（中心を高密度に） |
| `VXMAC_HUD=1` | オフ | HUD の四隅を中央付近に描き直す（`"u0 v0 u1 v1 x y s; ..."` で独自指定も可） |
| `VXMAC_VEL=0` | オン | ゲーム自身の速度バッファを動きベクトルに使う（映像と照合して確かめた後だけ） |
| `VXMAC_NPU=1` / `0` | オフ | ゲームの動きベクトルを使わないとき、フレーム間のオプティカルフロー（Vision）を使う |
| `VXMAC_VR_CACHE=0`、`VXMAC_VR_CACHE_DIM` | オン、0.8 | フレームの外の部屋のパノラマ、その明るさ |
| `VXMAC_VR_VIGNETTE` | 0.93 | フレームの縁を暗くし始める位置（0 でオフ） |
| `VXMAC_VR_ZOOM` | 1.0 | ゲームの FOV に対するフレームの見かけの大きさ |
| `VXMAC_STICK_PITCH=1` | オフ | 頭で操作中も右スティックの上下を有効にする |
| `VXMAC_GPU_WORKING_SET_MB` | 4096 | ゲームに伝える GPU メモリ量 |
| `VXMAC_AUTO_SCREEN=0` | オン | カットシーン（ゲームが頭の動きを受け付けないとき）でもスクリーンに切り替えず VR のままにします。映像は世界に固定され、ゲームが追従するまで入力は送りません。ヘッドセットでも覚えさせられます：カットシーンでスクリーンになっているときに両手ピンチで **VR** にすると「VR：カットシーンも VR のまま」、VR 中に **スクリーン** にすると自動切り替えが戻ります |

ソース中のその他の `VXMAC_*` はデバッグ用です。[`DESIGN.md`](DESIGN.md) を参照してください。

## 既知の問題（Preview 0.1）

項目は互いに独立しています。修正されたものはこの一覧から外します。

- **プレイ中は 60 W 以上の充電器を使ってください。** 弱い充電器（35 W など）では、この負荷で電力が足りなくなり、1〜2 分で
  約 45 Hz に落ちてカクつきます。60 W の充電器なら 90〜100 Hz を保ちます。
- **ゲーム 2.5.0（対応後）は英語音声のみ**（字幕とメニューは全言語で動きます）：ほかの言語の音声は Apple がホストするダウンロードで、App Store 版アプリ自身しか取得できません。
- **終了は両手の 3 秒ピンチで**（「安全な終了のしかた」）。アプリを閉じるとゲームは一時停止し、10 秒後に終了を求めますが、
  バックグラウンドでは終了しきれないことがあります。
- **1600x900 は M2 で約 40 Hz**：「推奨設定」の 1280x720 を使ってください。
- **ゲームデータの最初の複製は大きく時間がかかる**（ネットワーク越しに 158 GB）。
- **有料の Apple Developer Program が必要**（無料のアカウントでは、アプリに必要な 2 つのエンタイトルメントを付与
  できません）。署名のプロファイルにも期限があるので、切れたら `build` + `install` で更新してください。

## 制限

- **対応ビルドは 1 つだけ**：Mac App Store 版 Cyberpunk 2077 2.3.2（上記のハッシュ）。ゲームが更新されると実行
  ファイルが変わり、VX Mac が新しいビルドに対応するまで `prepare` が拒否します。準備したバージョンを保ってください。
- **メモリ**：アプリが使えるのは Metal 込みで約 8.2 GB。ゲームは設定を下げた状態で、ゲーム中に約 6.4〜6.6 GB を使い
  ます（ゲームには GPU のワーキングセットを 4 GB と伝えています）。設定を上げたり負荷の高い場所に行くと上限を越え、
  visionOS がアプリを終了させることがあります。
- **フレームレート**：ゲームは約 20〜30 fps。頭の動きは再投影で滑らかですが、速い振り向きや動く物体ではゲームの
  低いフレームレートが見えます（カクつき、縁の乱れ）。
- **オフラインのみ、Apple や CD PROJEKT RED のオンラインサービスは使えません**：自分のチームで再署名すると、ゲームの
  Game Center と iCloud のエンタイトルメントが外れます。Game Center はサインアウトした状態として扱われ、クラウド
  セーブはありません。GOG Galaxy とゲームのネットワーク通信はオフラインです。セーブはヘッドセット上のアプリの
  コンテナに保存されます。
- **開発用の署名**：プロビジョニングプロファイルの期限が切れるとアプリが開かなくなります。`build` と `install` を
  やり直してください（データとセーブは残ります）。
- **Mod は不可**。レイトレーシング、HDR も不可。ゲームが起動時にシェルコマンドを実行しようとして失敗しますが、影響は
  ありません（visionOS にはシェルがありません）。
- **HUD**：ゲームの HUD の四隅（ミニマップ、クエスト、体力）はフレームの端にあり、VR では見えにくい位置です。対処：
  ゲーム自体の HUD セーフゾーン（`settings --set HudSafezoneHor=0.5`）、または `VXMAC_HUD=1`（四隅の領域を中央付近に
  描き直す）。
- **フレームの下と周囲**：ゲームの映像は目の視野より狭く（FOV 100 でフレームの下に視野の約半分）、その部分は、ゲームが
  映した部屋のパノラマを暗くしたもの（`VXMAC_VR_CACHE`）で埋めています。ライブの映像ではないので遅れて古く見える
  ことがあります。`VXMAC_VR_CACHE=0` で黒になります。
- Neural Engine の機能（中心窩の超解像、コンポジタのフォビエーション）はビルドに含まれますが、より多くの実機で確認
  できるまで **既定ではオフ** です（「オプション」参照）。

## 配布しないもの、回避しないもの

このリポジトリには、ゲームのファイルも、ゲームから作ったものも含まれません：

- **ゲームのファイルなし**（実行ファイル、ライブラリ、アーカイブ、設定）：自分のインストールを自分のヘッドセットに
  複製します。
- **作業コピーなし**：作業コピーは自分の Mac で自分のバンドルから作り、自分のチームで署名します。
- 誰かの実行で生じた **シェーダ、キャッシュ、ログなし**。

リポジトリに含まれるゲームに関する情報：実行ファイルの SHA-256、15 個のプールサイズ命令のファイルオフセットと元の値・
新しい値（`tools/macho_prepare.py`）、4 つのイメージの名前、データの配置、`settings` が変更する設定の名前と値。

VX Mac はコピープロテクションや所有確認を除去、模倣、回避しません。Mac App Store 版の実行ファイルには FairPlay 暗号化が
ありません。VX Mac は App Store のレシート、StoreKit、Game Center、iCloud、GOG のアカウントに触れず、App Store の
バンドルに書き込むこともありません。自分で購入したコピーを、自分のためにだけ使ってください。VXpro と VeRantyx は CD PROJEKT RED
とも Apple とも無関係です。Cyberpunk 2077 は CD PROJEKT S.A. の商標です。

> このガイドは法的な助言ではありません。ゲームと Mac App Store の規約はご自身で確認してください。

## 安全について

- **VX Mac はサンドボックスではありません。** ゲームのコードは VX Mac Host アプリの全権限でネイティブに動きます：
  そのコンテナ、ネットワーク、許可したハンドトラッキングやワールドセンシング。境界は visionOS のアプリサンドボックス
  だけです。自分が所有し信頼するソフトウェアだけを動かしてください。
- ツールはヘッドセット上のものを削除せず、アプリをアンインストールしません。Mac 上では `build/` にだけ書き込み、
  インストール済みのゲームは読むだけです。
- ヘッドセットは熱を持ち、アプリはメモリの大半を使います。休憩を取ってください。VR で気分が悪くなったら中止して
  ください。

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| プレイ中にアプリが閉じる | 多くは visionOS のメモリ上限：最後のセーブをロードし、`settings --profile p720fixed`（推奨の設定）にして、セーブせずに長く遊ばない。`pull` して `vxmac_host.jsonl` の最後の `stats` 行の `footprint_mb` と `available_mb` を見る |
| `prepare`：「not Cyberpunk 2077 2.3.2」 | 別ビルドのゲーム：対応は Mac App Store 版 2.3.2 だけ |
| `build`：署名エラー／エンタイトルメントがない | 有料チーム（`doctor`）、自分のバンドル ID（`prepare --bundle-id`）、Xcode に自分のアカウントでサインイン |
| `copy` が止まる | `copy` をもう一度：続きから再開し、全ファイルを照合し直す。ヘッドセットをスリープさせず、その間に install しない |
| データなしで起動する（`vxmac_host.jsonl` に `game_data ... null`） | 複製が不完全か場所が違う：`copy`（照合する） |
| `launch` が「Acquired usage assertion」で止まる | ヘッドセットを装着してロックを解除する |
| 別のアプリを開くと映像が止まる | VX Mac Host が背面にある間、ゲームは待機する（visionOS は背面での GPU 処理を許さない）。戻れば続く |
| 「最初からやり直したい」 | アプリは **削除しない**（158 GB の複製とセーブが消える）。代わりに `install` し直す |
